# Demo script

Target: 3 minutes. Rehearse with the actual deployed URL and a local backup.

1. **Problem (20s):** who struggles, where, and why it matters.
2. **Outcome (15s):** one sentence describing what changes for that person.
3. **Live path (90s):** use one realistic input, show the main action, show the result.
4. **Trust (25s):** data handling, human control, AI limitations, fallback.
5. **Evidence (20s):** metric, test, interview, or before/after comparison.
6. **Close (10s):** what is working now and the next validation step.

## Recovery plan

- Keep a known-good sample input.
- Keep screenshots or a 60-second screen recording.
- Keep local mock mode working without network or keys.
- Know the exact restart commands in `README.md`.
